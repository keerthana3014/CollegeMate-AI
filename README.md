# CollegeMate-AI
RAG-Based College Information Chatbot using Python
CollegeMate-AI 🎓

RAG-Based College Information Chatbot using Python

📌 About the Project

CollegeMate-AI is an AI-powered chatbot designed to help students get information about their college. It uses Retrieval-Augmented Generation (RAG) techniques to retrieve relevant information and answer student questions.

✨ Features

- Answers college-related questions.
- Provides college information using a knowledge base.
- Uses semantic search to find relevant information.
- Built using Python and AI libraries.

🛠️ Technologies Used

- Python
- Sentence Transformers
- FAISS
- CPU-based processing

📂 Project File

- "CollegeMate_AI.ipynb" — Main project notebook.

🚀 How to Run

1. Download or clone this repository.
2. Open "CollegeMate_AI.ipynb" in Google Colab or Jupyter Notebook.
3. Install the required Python libraries.

4. Run the notebook cells in order.

🎯 Project Goal

To help students access college-related information quickly through an AI chatbot.
